1. Scope:
   Tenant isolation verification across document registry, job telemetry, and detail inspection endpoints.

2. Enforced Mechanisms:
   - Header Authorization: All requests via apiRequest() include `Authorization: Bearer <devToken>`.
   - Default Context: Tenant context resolves to "dev-default-tenant" or active authenticated session tenant.

     * GET /api/v1/documents returns only documents matching the requesting tenant.
     * GET /api/v1/jobs returns only jobs matching the requesting tenant.
     * POST /api/v1/documents/upload associates newly ingested documents with the active tenant_id.

3. Cross-Tenant Leakage Check:
   - Client components do not retain cross-tenant cached records in memory when workspace context changes.
   - Workspace selector resets active document query and job telemetry states.
