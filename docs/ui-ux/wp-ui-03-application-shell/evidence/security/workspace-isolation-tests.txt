Audit Findings & Verified Controls:

1. Server-Authoritative Multi-Tenancy:
   - Client workspace selector is purely an interface presentation control.
   - All backend document retrieval, question answering, cross-document comparison, and review operations require server validation of session credentials (X-Tenant-ID header or JWT tenant claim).
   - Switching workspaces in the frontend updates displayed state and triggers onWorkspaceSelect callback; it NEVER counterfeits authorization credentials or synthesizes backend records.

2. Open Redirect Prevention:
   - Function isSafeInternalHref(href) strictly enforces internal routing:
     * Allowed: "/documents", "/ask", "/compare", "/reviews", "/settings"
     * Blocked: "//attacker.com", "https://external.com", "javascript:alert(1)", "data:text/html"
   - Tested and verified in web/tests/unit/shell-state.test.ts (100% pass).

3. Zero Default Hardcoded Credentials:
   - Audited for hardcoded "default-tenant", "dev-token", or development bypass headers.
   - All production API calls route through standardized apiClient requiring authenticated context.
