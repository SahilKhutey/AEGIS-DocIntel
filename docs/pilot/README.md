# Pilot program

**Status: no external pilots have been completed.**

An earlier revision of this folder contained "case studies" and a "feedback log" with specific metrics. They could not be corroborated and were moved to `_unverified_archive/pilot/` (see the README there).

## How results get published here
- Every pilot result must link a **public GitHub issue** on the same line as the claim (enforced by `scripts/check_docs_claims.py`, rule R4).
- Use the *pilot feedback* issue template and the `pilot-feedback` label.
- `python scripts/pilot_dashboard.py` summarises those issues (GitHub is the only accepted source).
