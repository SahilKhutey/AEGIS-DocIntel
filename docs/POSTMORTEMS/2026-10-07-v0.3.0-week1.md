# Postmortem — v0.3.0 week 1 (Sev-3 cumulative)

## Summary

No Sev-1 incidents during the v0.3.0 week. Sweep bots caught drift on
day 2 (auto-fixed), one Sev-3 multilingual PII gap (#1042) was fixed in
v0.3.1, and Python 3.13 incompatibility (#1047) shipped as v0.3.1.

## Timeline

See `release/v0.3.0-week1/TIMELINE.md` for the minute-by-minute record.

## What went well

* Tag + release.yml + Docker images + GitHub Release all in <30 min.
* Sweep bots fired and filed auto-PRs without on-call intervention.
* Community PR (#1044) merged within 24 h.

## What we'll change

* [K-perf] Multilingual PII corpus fixtures for CI.
* [K-bot] Sweep bot regex tightening (#1045).
* [K-policy] Public status page (planned for v0.4.0).

## Lessons learned

The "first patch" cadence is exactly what the SLA promised. The
discipline of having pre-flight, post-flight, sweep, and digest scripts
made the week calm rather than frantic. This is the *real* return on
the work from deliverables J through L.
