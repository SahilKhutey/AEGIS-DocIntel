# Support

## Community channels

| Channel | Use it for |
| ------- | ---------- |
| GitHub Discussions | Questions, design proposals |
| GitHub Issues | Reproducible bugs, well-defined feature requests |
| `#aegis-docintel` (Matrix/Slack bridge — TBD) | Real-time chat, low-stakes questions |

## Commercial channels

* Email `support@aegis-docintel.invalid` (replace with project email).
* SLA enforcement: see `docs/SLA.md`.
* Severity response: see `docs/SLA.md#4-incident-response`.

## Issue labels

| Label | Meaning |
| ----- | ------- |
| `bug` | Defect |
| `security` | Security report (private until GHSA) |
| `K-deprecation` | Removing a deprecated name |
| `K-perf` | Performance improvement |
| `K-sdk` | SDK / protos |
| `K-ui` | Streamlit or React changes |
| `K-obs` | Observability |
| `K-stable` | Public API surface |
| `K-policy` | Process / docs / governance |
| `K-research` | Research-track (post-1.0 features) |
| `K-bot` | Bot-generated PR |
