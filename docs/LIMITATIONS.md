# System Limitations & Boundaries

**AEGIS-DocIntel Documentation Suite**  
**Version**: `1.0.0-rc.1`  
**Status**: `Approved & Audited`

---

## 1. Supported Document Limits
- Maximum single file size: 100 MB.
- Maximum page count per document: 500 pages.
- Supported languages: English, French, German, Spanish (UTF-8 Latin/Cyrillic).

## 2. Unsupported Scenarios
- Encrypted or password-protected PDF files without credentials provided.
- Audio recordings exceeding 60 minutes in a single chunk.
- Executable or embedded binary payloads within documents.
