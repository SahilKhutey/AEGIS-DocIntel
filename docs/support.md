# Support Policy & Triage Guidelines

Thank you for exploring and evaluating AEGIS-DocIntel.

---

## Where to Get Help

- **General Bugs & Issues**: Please submit a ticket via our [GitHub Bug Report Template](https://github.com/SahilKhutey/AEGIS-DocIntel/issues/new?template=bug_report.md).
  - *Triage Target*: 48 hours for an initial response. Please note that this is an early-stage project maintained by a small engineering team; we set expectations honestly and do not promise commercial 24/7 SLAs.
- **Pilot Program Participants**: Please submit feedback using the [GitHub Pilot Feedback Template](https://github.com/SahilKhutey/AEGIS-DocIntel/issues/new?template=pilot_feedback.md). These reports receive priority triage during active pilot validation cycles.
- **Security Issues**: Do NOT open public GitHub issues for security matters. Report them privately to `security@aegis-docintel.org` per the [Security Policy](security.md).
- **`aegis-docprep` Inquiries**: Questions regarding the standalone subpackage are tracked with priority since it has a focused, low-dependency maintenance surface.

---

## Issue Escalation & Severity Levels

| Severity | Criteria | Target Response |
|---|---|---|
| **Critical** | Core crash during cold-start or regression in `aegis-docprep` | 24–48 hours |
| **High** | Ingestion pipeline failure on standard PDF layouts | 2–3 business days |
| **Normal** | Documentation clarification, feature requests, research suggestions | Community triage |
