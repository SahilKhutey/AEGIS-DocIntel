## 4. Submodular Knapsack Approximation Guarantee Proof

Document context packing under token budget constraints is NP-hard. AEGIS-DocIntel employs a `SubmodularKnapsackPacker` combining greedy density ordering with a best-single-item fallback:

$$\text{Value}(S_{\text{greedy}}) \ge \frac{1}{2}\left(1 - \frac{1}{e}\right) \text{Value}(S_{\text{opt}}) \approx 0.316 \cdot \text{Value}(S_{\text{opt}})$$

- **Budget Feasibility:** $\sum_{c \in S} \text{tokens}(c) \le \text{MaxBudget}$ guaranteed across all inputs.
- **Adversarial Resiliency:** On counterexamples where pure greedy density fails (e.g. tiny item with density 0.02 fills remainder, blocking 1.0 value item), the fallback takes the single item, achieving $> 0.316 \times \text{OPT}$.
- **Verification:** Locked in by `tests/test_packer_guarantee_gap.py` and `tests/test_benchmark_proof.py`.

## 5. Information Retrieval & Economics Framework Proof

The benchmarking framework under `backend/benchmarks/` provides standardized IR evaluation:

1. **Accuracy Metrics (`accuracy.py`):**
   - Exact match evaluation
   - Token overlap $F_1$ score ($P \ge 0.5$ threshold)
   - Cosine semantic similarity evaluation
2. **Information Retrieval Metrics (`precision_recall.py`):**
   - Precision: $\text{TP} / (\text{TP} + \text{FP})$
   - Recall: $\text{TP} / (\text{TP} + \text{FN})$
   - $F_\beta$ score with configurable trade-off
3. **Token Economy & Cost Model (`cost.py`):**
   - Ingestion token accounting
   - LLM query token tracking (prompt vs. completion)
   - Configurable pricing per 1,000 and 1,000,000 tokens

## 6. How to Reproduce

All benchmarks can be independently reproduced using the following commands from the repository root:

```bash

python scripts/run_benchmark.py --corpus production/benchmark-dataset-real/pdf-corpus

# 2. Verify benchmark data integrity and IR metrics
pytest tests/test_benchmark_proof.py

# 3. Verify table extraction regression tests
pytest tests/test_table_extraction_regression.py

# 4. Verify submodular packing approximation bound
pytest tests/test_packer_guarantee_gap.py

# 5. Verify the 6-stage benchmarking framework components
pytest tests/test_benchmarks_framework.py
```
