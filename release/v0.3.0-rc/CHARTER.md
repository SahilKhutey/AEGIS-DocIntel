# Charter — v0.3.0 Release Candidate

## Scope

* Land Deliverable K (deprecation cleanup + sweep bots).
* Land Deliverable L (operational hardening).
* Tag `v0.3.0` and publish GitHub release + Docker images + Python wheels.

## Out of scope

* C++ SDK 1.0.0 (postponed to v0.4.0).
* Federated retrieval research (v0.5.0).

## Code freeze

* `master` is frozen for new features once `v0.3.0-rc.1` is cut.
* Bug fixes only, cherry-picked into `release/v0.3.0-rc`.

## Voting

* Three maintainers vote (>= 2 YES, <= 1 NO).
* See `release/v0.3.0-rc/VOTING.md` for the format.
