# Unverified pilot material — do not cite

These files describe pilot "case studies" and "feedback logs" with specific metrics. They are retained
for audit only because **nothing corroborates them**:

- the repository has never had a pilot issue, a star, a fork, or an outside contributor;
- the "feedback" cites issue numbers #1–#5 that do not exist on GitHub;
- results and the recruitment announcement were committed together by the maintainer in one commit
  (`88dc1ed`), with entry dates earlier than the commit.

This does not prove the pilots did not happen — it means they cannot be treated as evidence.
Policy going forward (enforced by `scripts/check_docs_claims.py`, rule R4): any quantified pilot claim
must link a public GitHub issue on the same line.
