# Security Policy

## Reporting Security Issues

Report security issues privately to **security@aegis-docintel.org** (or via GitHub Private Vulnerability Reporting) rather than as a public GitHub issue.

See [`production/security-audit/`](production/security-audit/) for the real, traced findings from our own internal review (Phase 10) — not a substitute for a real third-party audit, which we have not yet commissioned. If you find something we missed, we want to know.

## Supported Versions

| Version | Supported |
|---|---|
| `aegis-docprep` (standalone) | :white_check_mark: Yes |
| `AEGIS-DocIntel` (alpha platform) | :white_check_mark: Best effort (research alpha) |

## Response Expectations

- **Initial Triage:** Within 48 hours.
- **Remediation Target:** Critical vulnerabilities prioritized for resolution in minor patch releases.
- **Public Disclosure:** Coordinated disclosure after fix validation.
