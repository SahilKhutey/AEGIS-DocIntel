# AEGIS-DocIntel — Launch Reports & Metrics

This directory contains weekly progress reports, verification audit summaries, and post-launch retrospectives.

## Report Types
- `weekly/`: Weekly launch programme status reports generated by `.github/workflows/weekly-launch-report.yml`.
- `verification/`: Test execution outputs, benchmark results, and security scan logs.
- `post-launch/`: Conversion funnel analysis and launch retrospective (`PH-065` through `PH-070`).
